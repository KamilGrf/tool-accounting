# АС «Учёт инструментов» — frontend (ДЗ4, интеграция с PostgreSQL-backend — ДЗ5)

Одностраничное приложение на React для backend «Учёт инструментов» (`../backend`: Node.js + PostgreSQL в Docker). Запуск всей системы — в [../README.md](../README.md). Интерфейс построен по концепции 3 «Корпоративный» из ДЗ3: боковое меню, таблица и карточка выбранного инструмента.

## Возможности

| Экран | Что делает |
|---|---|
| **Вход / регистрация** | Вход по логину и паролю (сессия в HttpOnly-cookie), регистрация кладовщика, сообщение «Сессия истекла», выход |
| **Инструменты** | Поиск и фильтры (категория, статус), таблица, карточка с историей выдач, добавление инструмента, выдача, приём возврата, продление срока; списание — только руководитель |
| **Выдача и возврат** | Список выдач с фильтрами «Активные / Просроченные / Все», приём возврата, число дней просрочки |
| **Отчёт** (руководитель) | Плитки-показатели, категории, топ сотрудников, использование инструментов, просрочки, экспорт CSV |

На каждом экране обработаны состояния загрузки, ошибки (сетевой и серверной, с кнопкой «Повторить»), пустого списка и успеха. Интерфейс адаптивен: на ширине менее 1280 px карточка уходит под таблицу, менее 1024 px — меню становится горизонтальной лентой.

Чего нет: экранов управления сотрудниками и категориями (в API они есть).

## Стек

React 19 · React Router 7 · Vite 8 · Tailwind CSS 4 · Vitest 5 + Testing Library.

## Запуск

Нужны Node.js 22.5+ и запущенный backend (см. [../README.md](../README.md): `docker compose up -d --build`, API на порту 3001).

```bash
npm install
npm run dev
```

Откройте http://localhost:5173. Запросы `/api/*` проксируются на backend (адрес меняется переменной `API_TARGET`). Cookie сессии работает, потому что браузер видит один источник; для прямых запросов на другой порт нужен CORS (в backend он настроен через `CORS_ORIGINS`).

## Тесты и сборка

```bash
npm test          # 23 теста, backend не нужен (fetch подменяется)
npm run build     # продакшен-сборка в dist/
```

## Структура

```
src/
  api/          client.js (fetch, ApiError/NetworkError, таймаут), index.js (методы API)
  auth/         AuthContext (сессия, выход при 401)
  hooks/        useAsync (загрузка/ошибка/данные), useDebounced, useSubmit
  components/   ui.jsx (базовые элементы), forms.jsx (формы), Layout.jsx
  pages/        LoginPage, ToolsPage, IssuesPage, ReportPage
  utils/        format.js (даты, деньги)
  test/         setup.js, mockFetch.js
CLAUDE.md       правила для ИИ-агента (адаптация ДЗ2)
```

Процесс разработки с ИИ-агентом описан в [../backend_documentation.md](../backend_documentation.md); отчёт по ДЗ4 — в `ДЗ4/development_report.md`.
